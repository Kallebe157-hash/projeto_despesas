#  Projeto de Despesas Pessoais

Este é um projeto desenvolvido em **Python** com o objetivo de registrar, calcular e analisar despesas pessoais de forma simples e prática.

---

##  Sobre o projeto
Durante meus estudos de Python e Análise e Desenvolvimento de Sistemas, criei este projeto para aplicar conceitos como:
- Estruturas de dados (listas, dicionários)
- Manipulação de arquivos CSV
- Funções e modularização
- Análise de dados com bibliotecas Python

O sistema permite adicionar, listar e calcular o total de despesas, registrando tudo em um arquivo `.csv`.

---

##  Tecnologias utilizadas
- Python 
- Pandas (opcional)
- CSV
